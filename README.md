# Baku-Templates

Katalog & Repositori Resmi Berkas Templat Dokumen Baku PDF (`.baku`) untuk Komunitas Perguruan Tinggi, Akademisi, dan Lembaga Resmi di Indonesia.

Repositori ini berfungsi sebagai pusat distribusi berkas templat terbuka (*open templates registry*) yang terhubung langsung dengan website resmi [**bakupdf.tech/templates**](https://bakupdf.tech/templates) dan aplikasi desktop **Baku PDF**.

## 🚀 Cara Menggunakan Berkas .baku di Aplikasi Baku PDF

1. Unduh berkas `.baku` yang Anda inginkan dari repositori ini atau via tombol **Unduh** di [bakupdf.tech/templates](https://bakupdf.tech/templates).
2. Buka aplikasi desktop **Baku PDF**.
3. Klik menu **File** &rarr; **Impor Templat (.baku)**.
4. Pilih berkas `.baku` yang baru saja Anda unduh.
5. Templat akan otomatis tersimpan di ruang kerja (*workspace*) lokal Anda dan siap dipakai untuk menyusun dokumen baru.

## 🤝 Cara Berkontribusi (Bagikan Format Kampus Anda)

Kami mengundang mahasiswa, dosen, asisten laboratorium, dan praktisi di seluruh Indonesia untuk menyumbangkan format templat resmi kampus masing-masing.

Ada dua jalur mudah untuk berkontribusi:

### 1. Jalur Instan via Web (Tanpa Perlu Akun GitHub)
Buka [**bakupdf.tech/templates**](https://bakupdf.tech/templates), klik tombol **Bagikan Format Kampus Anda**, unggah berkas `.baku`, dan sistem akan otomatis membuatkan tiket kerja Pull Request ke repositori ini atas nama Anda.

### 2. Jalur Developer (GitHub Fork & Pull Request)
Silakan baca panduan lengkap pada berkas [**CONTRIBUTING.md**](CONTRIBUTING.md).
